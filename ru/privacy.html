Политика конфиденциальности

Poster · обновлено 24 сентября 2026

Poster — инструмент публикации, который работает на собственном сервере. Он ставит видео в расписание и публикует их в аккаунты соцсетей, которыми владеет оператор установки и которые он подключил сам. Облачного сервиса, регистрации и базы пользователей нет: каждую установку ведёт один человек на своём сервере для своих аккаунтов.

Политика описывает программу и эталонную установку её автора. Тот, кто разворачивает свою копию, становится её оператором и отвечает за неё.

Что хранит программа

  • Токены доступа подключённых аккаунтов (TikTok, YouTube, Instagram, VK) — в зашифрованном виде в собственной базе оператора.
  • Видео и подписи, которые оператор загружает для публикации, — файлами на собственном сервере оператора.
  • Записи о публикациях: время поста, площадка, идентификатор и адрес поста, ошибка, если площадка её вернула.
  • Публичная статистика с площадок: число просмотров, лайков, комментариев и репостов, число подписчиков и текст комментариев под собственными постами оператора.

Чего программа не делает

  • Не собирает данные ни о ком, кроме собственных аккаунтов оператора и публичной реакции на его собственные посты.
  • Не продаёт, не сдаёт в аренду и не передаёт данные третьим лицам, не содержит рекламных и аналитических трекеров.
  • Не читает личные сообщения, списки друзей и любой контент других пользователей.
  • Не передаёт данные никуда, кроме API площадок, нужных для публикации поста и чтения его публичной статистики.

Куда уходят данные

Данные остаются на собственном сервере оператора и в API площадок, с которыми он работает: TikTok, YouTube (Google), Instagram (Meta) и VK. Каждая площадка обрабатывает полученные данные по своей политике конфиденциальности. Площадкам, которые забирают видео по ссылке (Instagram и TikTok), файлы отдаются по ссылкам, которые перестают работать через несколько часов.

Хранение и удаление

Записи о публикациях и статистика хранятся, пока они нужны оператору, и могут быть удалены из базы в любой момент. Отключение аккаунта удаляет его токены. Удаление установки удаляет все данные. Отзыв доступа Poster в настройках самой площадки сразу прекращает любой дальнейший доступ, что бы ни хранилось локально.

Безопасность

Токены доступа зашифрованы ключом, который есть только у оператора: копия базы без этого ключа не даёт доступа ни к одному аккаунту. API управления требует токен; без него доступен только адрес, с которого площадки забирают видео, и ссылки на него подписаны и живут недолго.

Дети

Poster — инструмент для оператора установки и не предназначен для детей.

Изменения

Если политика изменится, новая версия будет опубликована по этому адресу с новой датой.
