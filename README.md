# poster-site

Личный сайт Валентина Москалёва и публичные страницы проекта
[Poster](https://github.com/xNa1D/poster) — своей системы постинга в TikTok,
YouTube, Instagram и VK.

Две копии одного сайта: английская на `xna1d.com`, русская на `xna1d.ru`.
Переключатель языка на каждой странице ведёт на ту же страницу другого домена.

Страницы Poster нужны потому, что площадки требуют при регистрации приложения
публичные адреса страницы приложения, условий использования и политики
конфиденциальности, а у self-hosted инструмента сайта иначе нет.

## Что внутри

* `index.html` — главная: кто я, соцсети, проекты.
* `poster.html` — страница приложения Poster: что делает, какие площадки.
  Это Web/Desktop URL в формах TikTok, Meta и VK.
* `terms.html` — условия использования Poster. Ключевое: аккаунты только свои,
  гарантий работы чужих API нет.
* `privacy.html` — политика конфиденциальности Poster. Ключевое: данные не уходят
  никуда, кроме API площадок; токены зашифрованы на машине владельца.
* `callback.html` — страница возврата после авторизации. Показывает адрес
  с кодом, чтобы перенести его в локальный скрипт; сама ничего не отправляет
  и секретов не знает.
* `ru/` — те же страницы по-русски, корень сайта `xna1d.ru`.

Правка страницы — правка обеих копий: английской в корне и русской в `ru/`.

## Чего здесь быть не должно

Кода публикатора (он в приватном репозитории `poster`), любых ключей и
токенов, аналитики и трекеров — политика прямо обещает, что их нет.

## Публикация

nginx на сервере `5.129.211.208`: `xna1d.com` отдаёт корень репозитория,
`xna1d.ru` — папку `ru/`. Выкладка — push в `main`, затем на сервере
`git -C /var/www/xna1d.com pull`. Сертификаты Let's Encrypt (certbot,
продление по таймеру). GitHub Pages (`xna1d.github.io/poster-site`) остаётся
зеркалом, пока в формах площадок не заменены адреса.
