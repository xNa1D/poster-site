# poster-site

Публичный сайт проекта [Poster](https://github.com/xNa1D/poster) — своей системы
постинга в TikTok, YouTube, Instagram и VK.

Существует по одной причине: площадки требуют при регистрации приложения
публичные адреса главной страницы, условий использования и политики
конфиденциальности, а у self-hosted инструмента сайта иначе нет.

## Что внутри

* `index.html` — главная: что делает инструмент, какие площадки, ссылки на
  документы. Это Web/Desktop URL в формах TikTok и VK.
* `terms.html` — условия использования. Ключевое: аккаунты только свои,
  гарантий работы чужих API нет.
* `privacy.html` — политика конфиденциальности. Ключевое: данные не уходят
  никуда, кроме API площадок; токены зашифрованы на машине владельца.
* `callback.html` — страница возврата после авторизации. Показывает адрес
  с кодом, чтобы перенести его в локальный скрипт; сама ничего не отправляет
  и секретов не знает.

## Чего здесь быть не должно

Кода публикатора (он в приватном репозитории `poster`), любых ключей и
токенов, аналитики и трекеров — политика прямо обещает, что их нет.

## Публикация

GitHub Pages с ветки `main`, корень репозитория. Правка страницы = push в main.
